What's inside

One namespace, numerix::, organised into focused modules.

Math core

Templated Complex<T>, algebra helpers and numeric utilities with sane double defaults.

Matrix & algebra

Matrices, rotations, decompositions and a Kalman filter for state estimation.

Geometry

Segments and clothoids for path and curve modelling.

Statistics

Normal distribution PDF/CDF and the primitives that build on them.

Finance

Black–Scholes option pricing, exposed to both C++ and Python.

Geo

Coordinate conversion (lat/lon ↔ UTM) and time converters.

Coding

Huffman coding for compact, prefix-free encoding.

Utility

Logger, INI / CSV / XML parsers, progress bar, colour output and more.

Integrations optional

Wrappers for the Point Cloud Library (PCL) and Eigen3, behind CMake feature flags.

Quick start

Build the library and run the test suite — Ninja is the default generator.

# clone
git clone https://github.com/ESeNonFossiIo/numerix.git
cd numerix

# configure & build
mkdir -p build && cd build
cmake -D CMAKE_BUILD_TYPE=Release -D ENABLE_ALL_TESTS=ON ..
ninja -j4

# run the tests
ctest --output-on-failure

Python bindings

The numerixpy package calls into the compiled core via ctypes.

# build the shared library and a conda-backed env
cmake -D BUILD_PY_ENV=ON .. && ninja -j4

# run the Python test suite
build/numerixpy_env/bin/python -m pytest python/tests/ -v
from numerixpy.finance.black_scholes import call_price

price = call_price(spot=100, strike=100, rate=0.05,
                   vol=0.2, maturity=1.0)
print(price)

Function signatures may vary by version — see the package under python/numerixpy/.
